Section header new

one shell · title · filters · toggle

Metric / ratio card new

numbers first · minimal text

For cards where a few figures carry the whole story — the Efficiency ratios card, cost-per-unit, throughput. The number is the hero; everything else earns its place by giving that number meaning: a label of what it measures, a trend vs. the last period, and one light visual (a coverage meter or a sparkline) so the figure is scannable, not just stated.

Grouped stat list new

label → value · too few for a table

A handful of label → value rows split into two or three columns — the Cadence / Delivery / Cost spread and Tool calls / Context / Ecosystem cards. It's for data that's table-shaped but too sparse to justify a real table. Two things it fixes: the column header now uses the system's mono-uppercase label (not the display sans, which read as foreign), anchored by a rule; and the rhythm is regularised — even gutters, one row cadence, full-height dividers regardless of uneven row counts.

Multi-column text card new

long-form copy inside the card system

Two variants for narrative content — an executive summary, methodology notes, a changelog. Editorial flows one body of text across balanced columns with a drop-cap. Structured splits into headed, numbered columns for parallel points. Both collapse to a single column on mobile.

Editorial columnsflowing · drop-cap

This 30-day window cost $6.62 across 39 sessions — 18% above the prior month, driven almost entirely by a single project migrating to Opus 4.8. The headline number hides a healthier story underneath.

Cache did the heavy lifting: 99% of tokens were served from cache reads rather than billed fresh, holding the effective rate to roughly $0.17 a session. Without that read/create ratio of 10:1, the same work would have cost several times as much.

Spend clusters on weekday afternoons, peaking Wednesday at 3 PM. Weekends barely register, which suggests the tool is doing focused, working-hours work rather than idle exploration — a useful signal when deciding where to invest next.

The projection to a full 30 days lands near $8.10 if the current run-rate holds. Nothing here left the machine; every figure was read from local session logs.

Structured columnsheaded · numbered

01

What it reads

Local session logs only — cost, tokens, cache splits, timestamps, model, and project. No network calls, no upload, no account required.

02

How it counts

Every dollar is itemised per session and rolled up by day, model, and project. Cache reads are separated from creates so the real bill is visible.

03

Why it matters

Cost-per-hour of focus, not idle minutes. Knowing where budget goes turns an opaque subscription into a line-item you can actually manage.

Section floating sidebar new

navigate · reorder · hide

A persistent rail pinned to the edge of the report. Collapsed it reads as a stack of ticks — one per section, the current one in clay. On hover it opens into the “go to section” menu, where each row carries a drag handle to re-order and an eye to hide the section. In production it lives position:fixed against the right edge; here it's placed inside a demo stage so you can see both states.
